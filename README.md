# 智构千年：古建筑斗拱智能交互平台

竞赛项目的源码归档，默认分支为 `old`。

## 模块

| 目录 | 内容 |
| --- | --- |
| `agent/` | FastAPI Agent 服务：意图路由、视觉工具调用、知识检索和回答生成 |
| `ancient_arch_backend/` | FastAPI 视觉后端：分类匹配、分割、修复与模型资源接口 |
| `ancient-architecture-agent/` | React + TypeScript + Vite 前端 |

各模块的依赖安装和启动方式见其目录内的 README。当前实现与检查记录见 [项目分析](项目分析.md)。

## 本仓库的内容范围

仓库保留源码、依赖清单、配置示例、小型 JSON 元数据、知识文本缓存、数据划分文件和修复训练日志。

按照归档要求，以下内容保留在本地，不上传到 GitHub：

- 模型权重、特征文件和 FAISS 索引。
- 原始图片、mask、渲染图片和测试图片数据。
- 三维模型、人物素材及前端 `public/` 资源。
- 真实 `.env`、依赖目录、构建产物和运行缓存。

克隆本仓库后，需要另行准备上述资源并按配置放置，才能完整运行识别、修复和三维展示。仅有源码不代表这些链路已完成运行验证。本次源码归档无需下载 Git LFS 对象。
